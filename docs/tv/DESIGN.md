# Kazumi for TV —— 设计稿 v1.1（已拍板）

> 基线：`Zhang0010/Kazumi-for-TV` @ `7265274`（= 上游 v2.4.3，fork 目前无自改代码）
> 目标：同一套代码同时支持 手机 / 桌面 / Android TV，TV 上纯遥控器（DPAD + OK + BACK + MENU，无触摸、无鼠标）
> 本文档只描述设计，不含实现。v1.1 = 五个待定项定稿；因「OK=播放/暂停」，播放键位表整表重排（§3.3），并新增触摸移除表与功能保留表（§3.5 / §3.6）。
>
> **决议（2026-11-08）**
> 1. minSdk **保持 24**（`flutter.minSdkVersion`），不动 `build.gradle`。
> 2. 无 OSD 时 **OK = 播放/暂停**；OSD 改由方向键呼出。
> 3. 同一 APK + 运行时判定；**TV 形态下播放器不保留任何触摸手势**，全部走电视常规逻辑，**播放器内功能一个不少**。
> 4. 搜索**调系统默认输入法**，不做自绘键盘。

## 1. 兼容性与构建

- **minSdk 保持 24 不变**（决议）。API 24 = Android 7.0，覆盖所有目标机型；`LEANBACK_LAUNCHER`、`banner`、`uses-feature` 都不需要更高 API。代价仅是偶发要写 `if (sdk >= 26)` 的能力判断，可接受——不为省这点分支去动打包配置，出货包与上游一致、升级上游时不会冲突。
- **一套代码两种形态**：启动时判定 `AppMode.tv`
  ```
  isTv = pm.hasSystemFeature(FEATURE_LEANBACK)
      || (uiMode & UI_MODE_TYPE_MASK) == UI_MODE_TYPE_TELEVISION
      || !pm.hasSystemFeature(FEATURE_TOUCHSCREEN)
  ```
  设置里给「界面模式：自动 / 电视 / 手机」，允许强制覆盖（调试和通用盒子都用得上）。
- **构建开关**：`--dart-define=KAZUMI_TV=true` 出 TV 专用包（默认进 TV 模式 + 横屏），普通包保持手机 UI。两者共用代码，不分叉。
- **Manifest**（TV 包）
  - `MainActivity` 增加 `<category android:name="android.intent.category.LEANBACK_LAUNCHER"/>`
  - `<application android:banner="@drawable/tv_banner">`（320×180）
  - `<uses-feature android:name="android.software.leanback" android:required="false"/>`
  - `<uses-feature android:name="android.hardware.touchscreen" android:required="false"/>`
  - `screenOrientation="sensorLandscape"`（仅 TV 包）
- **真机**：海信 VIDAA 投影（MT9653 / Android 11 / arm64 / 1920×1080）作为验收机。

## 2. 交互总原则（TV 形态）

1. **焦点永远可见**：3px 白描边 + 外发光 + scale 1.05，150ms 过渡。没有"猜焦点在哪"的情况。
2. **焦点有记忆**：返回上一级时回到离开时的元素（每个 tab 记 `lastFocusedKey`）。
3. **焦点到边缘自动滚动**：网格/列表用 `Scrollable.ensureVisible(alignment: 0.5)`，同时触发分页预取。
4. **长按 = 上下文菜单**（电视惯例）：长按 OK 打开该条目的更多操作，取代手机上的长按/右滑。
5. **无 hover**：所有"悬停才显示"的信息（简介浮层、卡片信息、OSD）改成"焦点即显示"或按键触发。
6. **防误触**：根页面 BACK 需连按两次退出；播放页 BACK 先收 OSD，再退页面。
7. **每个动作都有 HUD 反馈**：seek、音量、倍速、弹幕开关，屏幕中央/左上角浮现 1.2s。
8. **尺寸规范**（1920×1080 基准）：安全边距 48px；最小可交互块 64×64；正文字号 ≥ 20sp；标题 32–44sp；卡片间隙 24px。

### 3.3 播放页（核心，分三个状态）

**状态 A：OSD 隐藏（沉浸观看）**

> 决议：`OK` 就是播放/暂停（Kodi / 手机心智），OSD 改由方向键呼出。触屏的单击 / 双击 / 长按 / 滑动在 TV 形态下一律不注册（见 §3.5）。

| 按键 | 行为 |
|---|---|
| **OK / ENTER (23/66)** | 播放 / 暂停；画面中央 HUD 闪 `▶ / ⏸` 1s，**不呼出 OSD** |
| **长按 OK**（≥500ms） | **选集抽屉**（右侧滑入，电视惯例：长按=上下文面板） |
| ↑ | 呼出 OSD，焦点落**顶部栏**（返回 / 标题集数 / 线路 / 弹幕 / 更多） |
| ↓ | 呼出 OSD，焦点落**底部按钮行**（▶ ⏮ ⏭ 进度 倍速 CC ⛶） |
| ← / → | 快退 / 快进 10s，HUD 显示 `00:12:34  −10s`（不呼出 OSD） |
| **长按 ← / →** | 连续 seek：每 400ms 加速一档 1x→2x→4x→8x，松手 800ms 后落定 |
| MENU (82) | 播放设置菜单（倍速 / 字幕 / 音轨 / 画面比例 / 软件音量） |
| MEDIA_PLAY_PAUSE (85) | 同 OK：播放 / 暂停 |
| MEDIA_NEXT / PREV (87/88) | 下一集 / 上一集 |
| BACK | 退出播放页（回详情），自动记录进度 |

- **音量不再占 ↑↓**：电视/投影自带音量键，交给硬件；软件音量（`media_kit` 0–100）放在 MENU → 播放设置里。
- 设置项保留覆盖：「无 OSD 时方向键」= `呼出 OSD（默认）/ 音量 ±5 / 上一集下一集 / 无操作`，给习惯老式盒子的用户留出口。
- MENU 键不少遥控器没有：**选集**有 `长按 OK` 兜底，**字幕/倍速/全屏**有 OSD 底部按钮兜底，核心操作不依赖 MENU。

**状态 B：OSD 显示中**

> 焦点落点由呼出键决定：`↑`→顶部栏，`↓`→底部按钮行，再次按 `OK` 呼出（设置可改）→进度条。

| 按键 | 行为 |
|---|---|
| ← / → | 焦点在进度条时为 seek ±10s；在按钮行时为横向移动 |
| OK | 进度条上=进入拖动（再按落定）；按钮=执行 |
| ↑ | 进度条 → 顶部栏 |
| ↓ | 进度条 → 底部按钮行 |
| BACK | 收起 OSD（不退出播放） |
| 5s 无操作 | 自动收起（设置可选 3/5/10s / 常显） |

**状态 C：抽屉 / 弹窗（选集、倍速、字幕、弹幕输入）**

| 按键 | 行为 |
|---|---|
| ↑ ↓ ← → | 在抽屉内移动，焦点不出抽屉（`FocusTraversalGroup` 限制） |
| OK | 选中并关闭抽屉（选集即开始播放） |
| BACK | 关闭抽屉，焦点回到呼出它的按钮 |
| 长按 ↓（抽屉关闭时） | 弹幕快捷短语（`2333` `前方高能` `名场面` `泪目`），再选「键盘输入」才调系统 IME |

### 3.4 为什么这样分状态

- 遥控器只有 5 个键，**必须靠状态复用按键**：`←/→` 在无 OSD 时是 seek，在 OSD 时是移动焦点，在进度条上又是 seek——靠"焦点在哪"消除歧义，而不是加键。
- `OK` = 播放/暂停（决议）：遥控器最高频的键给最高频的动作，也与手机/桌面/`media_kit` 既有行为一致；「看进度 / 选集」用 `↓`（OSD）和 `长按 OK`（选集抽屉），两步可达，不再牺牲暂停的手感。
- `BACK` 分两级（先收 OSD 再退页面），避免看到一半误退出。

### 3.5 TV 形态下移除的触摸 / 鼠标逻辑

TV 判定为真时（`--dart-define=KAZUMI_TV=true` 或运行时判定），以下分支**不注册**；手机 / 桌面形态行为零变化（同一 widget 内 `if (!AppMode.isTv)` 包裹）。

| 现有实现 | 位置 | TV 形态处理 |
|---|---|---|
| hover 显示 OSD | `player_item.dart:1385` `MouseRegion.onHover` | 不注册（TV 无 hover），OSD 交给 §3.3 键位状态机 |
| 滚轮调音量 + 呼 OSD | `player_item.dart:1405` `Listener.onPointerSignal` | 不注册 |
| 单击显隐 OSD / 双击 seek ±10s / 长按 2x 倍速 | `player_item.dart:1437` `GestureDetector` | 不注册 → 改 `←→`（seek）、`长按 ←→`（连发）、`长按 OK`（选集） |
| 横滑 seek、竖滑音量/亮度 | `player_gesture_detector.dart:45` `Listener` + `GestureDetector` | 不注册（整块不挂载） |
| 进度条 hover 预览 + 拖拽 | `player_progress_bar.dart:167` `MouseRegion` + `RawGestureDetector` | 改按键：`←→` ±10s、长按连发、状态 B 下 `OK` 进出拖动 |
| 「长按保持面板不消失」 | `player_panel_hold.dart:72` `PlayerPanelHoldMouseRegion` | 改用自动隐藏计时器，任意按键重置计时 |
| 弹幕输入框点按聚焦 | `player_item_panel.dart` TextField | 焦点进入 + `OK` 调起系统 IME |

要点：触屏手势不是"屏蔽触摸事件"，而是**整块不进树**——否则 GestureDetector 会吃掉方向键之外的竞争手势，且 hover 计时器在 TV 上永远不触发（面板永不显隐）。

### 3.6 播放器功能保留清单（TV 上逐条有键路径，功能一个不少）

| 功能 | TV 路径 |
|---|---|
| 播放 / 暂停 | `OK`、`MEDIA_PLAY_PAUSE`、OSD 底部 ❚❚ |
| 进度 seek（10s / 30s / 5min 档） | `←→` 短按；长按连发；状态 B 进度条 `OK` 拖动 |
| 选集 | `长按 OK` 抽屉；OSD 顶部「选集」；结束后自动连播倒计时 |
| 上一集 / 下一集 | `MEDIA_NEXT/PREV`；OSD 底部 ⏮ ⏭；设置可把 ↑↓ 改成切集 |
| 倍速 | `MENU` → 倍速；OSD 底部 `1.0x` |
| 字幕（开关 / 外挂加载 / 延迟 / 样式） | `MENU` → 字幕；OSD 底部 `CC` |
| 音轨切换 | `MENU` → 音轨 |
| 画面比例 / 全屏 | `MENU` → 画面比例；OSD 底部 `⛶` |
| 线路 / 清晰度切换 | OSD 顶部「线路 ▾」；详情页 `MENU` |
| 弹幕开关 / 透明度 / 字号 / 速度 / 屏蔽词 | OSD 顶部「弹幕 ▾」→ 二级菜单；设置页「弹幕」分类 |
| 弹幕发送 | 抽屉关闭时 `长按 ↓` → 快捷短语；「键盘输入」→ 系统 IME |
| 锁屏防误触 | `MENU` → 锁定；锁定时仅 `OK` 解锁 |
| 截图 / 画面旋转 | `MENU` → 更多 |
| 自动连播 / 进度记忆 | 设置页「播放」；结束 5s 倒计时 + `OK` 立即播 |
| 软件音量 | `MENU` → 播放设置（默认交给电视音量键） |
| 播放器设置全量（硬解 / 缓冲 / 内核 / 代理） | 设置页「播放」原样保留，TV 只调布局不改项 |

```
 ① 使用约定（一屏读完，OK 同意 / BACK 退出）  →  ② 自动导入规则源（进度条，可跳过）
```

- 「更新来源」沿用默认（GitHub），不做选择页；

## 7. 风险与待定

1. **media_kit / libmpv 在 MT9653（Mali-G52）上的硬解兼容** —— 需要在 P1 就用真机跑 1080p H.264/HEVC 与只带 DTS 音轨的片源，确认有画面有声音。
2. **Flutter 焦点在 TV 上的"焦点丢失"** —— 空列表/对话框关闭后焦点可能归零，需要统一的 `FocusScope` 兜底策略（P0 建立规范）。
3. **规则源里的验证码/网页交互** —— TV 无触摸走 WebView 很痛苦；建议在 TV 上把这类源标为「需手机端完成授权」，不阻塞主流程。
4. **plugin_editor / 下载管理** —— 不做 TV 适配，前者只读查看，后者只显示进度。
5. **搜索输入（已定：系统默认 IME）** —— 残余风险：个别盒子/投影的 IME 在 Flutter 全屏页上弹窗位置或焦点会异常，P2 真机验证；若确实不可用，降级为「最近搜索 + 热门标签 + 拼音首字母匹配」，不退化成自绘全键盘。
